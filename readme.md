# ArUco Detect Position 
This branch for detect position of ArUco marker with camera

### Clone Github 
```
git clone https://github.com/SUNTADTAWAN/MiniCarver.git
``` 

### Activate Environment
```
source aruco_env/bin/activate
```

### Run 
```
python3 ArUco_Pose.py
```
 
**You need to calibrate your camera first**
